Browser Object Model (BOM)

1. Window Object

Window object represents the browser window.

2. Screen Object

Screen object provides information about the user's screen.

3. Location Object

Location object provides information about the current URL.

4. History Object

History object allows navigation through browser history.

5. Navigator Object

Navigator object provides browser and device information.

6. Popup Boxes

JavaScript provides different popup dialog boxes.

7. Cookies

Cookies store small information in the browser.
