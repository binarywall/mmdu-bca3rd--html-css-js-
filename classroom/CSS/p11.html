5. Scrollbar

CSS allows developers to control the dimensions of HTML elements. The width and height properties define the size of an element. The min-width and max-width properties control the minimum and maximum size. Similarly, min-height and max-height control the vertical dimensions. CSS outlines are drawn outside the border of an element. Lists can be customized using different marker styles. Cursor properties change the appearance of the mouse pointer when it moves over an element.
